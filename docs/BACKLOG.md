# Backlog / future ideas

This file contains stretch ideas that are deliberately outside the current product scope.

- Docker deployment and production environment hardening
- Redis caching and stale-slot invalidation
- Rescheduling workflow with a dedicated UI path
- Calendar export (.ics) for staff and customers
- SMS reminders and cancellation messages
- Staff performance analytics and utilisation reporting
- Multi-location / branch support
- Recurring appointments and follow-up bookings
- Bulk service packages and bundles
- API webhooks for downstream systems

These items are intentionally deferred and should not be implemented in the current build unless the product spec is changed.
